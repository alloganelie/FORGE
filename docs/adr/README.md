# Décisions d'architecture (ADR) du dépôt

Les ADR ci-dessous documentent les choix **d'implémentation** du dépôt. Ils
mettent en œuvre les ADR de la spécification technique (section 4) et ne les
remplacent pas. Une nouvelle dépendance ou une nouvelle règle de frontière
exige un ADR avant d'être introduite.
