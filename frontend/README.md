# Interface Next.js (MS-2)

Squelette App Router, TypeScript strict. L'en-tête affiche **FORGE** (Q-001) ;
les statuts R, C, A, D et V sont présentés séparément par StatusStrip.

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

Aucune règle métier ne doit être ajoutée ici : l'interface appelle l'API.
